A persistent on/off setting. Never use it to trigger an action.

```jsx
<Field orientation="horizontal">
  <FieldContent>
    <FieldTitle>Keep the screen awake</FieldTitle>
    <FieldDescription>Cook mode won't dim while you're following a recipe.</FieldDescription>
  </FieldContent>
  <Switch defaultChecked />
</Field>
```

`size="xl"` for cook-mode settings; `sm` inside dense list rows.
