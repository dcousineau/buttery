Gingham trim — the red-and-white check that signals "Betty Crocker cookbook" without taking over the page.

```jsx
<header style={{ borderBottom: "2px solid var(--border)", background: "var(--background)" }}>
  <div>…header row…</div>
</header>
<GinghamBand />
```

Rules, non-negotiable: bands only (14px), at chrome edges only, cream stays dominant, and never behind recipe content. It's built from two overlapping repeating gradients — never an image.
